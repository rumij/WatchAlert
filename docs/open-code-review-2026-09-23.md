| 高 | 安全 | `internal/services/datasource.go:153-160`、`api/datasource.go:107-116` | 数据源详情路由校验的是请求头租户，但服务按全局数据源 ID 读取后没有比较记录的租户。持有自己租户权限的用户若知道另一租户的数据源 ID，可读到该记录，且响应除 Zabbix Token 外包含其他凭据字段。 | 仓储查询同时使用数据源 ID 和已认证租户 ID；按字段屏蔽所有凭据。 |
